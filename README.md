# CloudCost Tracker

CloudCost Tracker is a cloud budgeting and cost management dashboard developed for **ITC6355 – Web App Design & Development** at Northeastern University.

The project demonstrates the use of **HTML5, CSS3, and JavaScript** to create a modern, responsive, and interactive web application that helps users monitor cloud spending, review service usage, and plan project budgets.

---

## Project Overview

CloudCost Tracker provides a centralized dashboard for viewing cloud spending metrics, tracking service categories, monitoring budget utilization, and submitting sample budget requests.

The application was designed to simulate a lightweight cloud cost management platform while applying modern web development practices and accessibility considerations.
