# CloudCost Tracker

CloudCost Tracker is a Week 1/2 HTML5 project for ITC6355 Web App Design & Development.

## Project Description

CloudCost Tracker is a static cloud budgeting dashboard that helps users view cloud service categories, estimated monthly costs, and sample budget request information.

## Pages Included

- index.html - Home dashboard overview
- services.html - Cloud services being tracked
- costs.html - Estimated monthly cost report
- budget.html - Budget request form
- documentation.html - Scope and design documentation page
- docs/CloudCost_Tracker_Project_Documentation.docx - Formal project documentation

## Week 1/2 Focus

This version focuses on HTML5 only. CSS and JavaScript will be added in later weeks.

## Future Enhancements

- CSS3 styling and responsive dashboard layout

- JavaScript filtering and alerts
