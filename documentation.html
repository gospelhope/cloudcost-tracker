Project Scope

CloudCost Tracker is a static web application that helps users view sample cloud services, estimated costs, budget status, and budget request information. The first version focuses on HTML5 structure only.

Design Plan

  1. Create semantic HTML5 pages with clear navigation.
  2. Use tables to display cost data.
  3. Use forms to collect sample budget requests.
  4. Use sections, articles, asides, figures, and details to organize content.

Future Enhancements

Week 2 and Week 3: CSS3

Add colors, layout, spacing, responsive design, cards, and dashboard styling.

Week 4 and Week 5: JavaScript

Add cost calculations, service filtering, budget alerts, and form validation.
